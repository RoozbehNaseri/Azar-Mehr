# Frontend Task | Nuxt.js Architecture Showcase

این مینی‌پروژه به عنوان یک نمونه‌کار جهت بررسی تسلط بر معماری فرانت‌اند، ساختاردهی اصولی پروژه‌های مقیاس‌پذیر و رعایت استانداردهای Clean Code در بستر فریم‌ورک Nuxt.js توسعه داده شده است. 

هدف از پیاده‌سازی این ساختار، نمایش درک عمیق از چرخه حیات کامپوننت‌ها (Lifecycle Hooks)، مدیریت بهینه State و جداسازی منطق برنامه از لایه رابط کاربری (UI) می‌باشد.

##  Tech Stack & Tools

- **Core Framework:** Nuxt.js (Vue 2) - *SPA / SSR Context*
- **State Management:** Vuex - *Modular Architecture*
- **Styling & UI:** SCSS / Vuetify - *Responsive Design*
- **Network / API:** Axios - *Nuxt Axios Module with Interceptors*
- **Testing:** Jest - *Unit Testing Setup*
